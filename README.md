# MBG-Tracker

Aplikasi web MBG Tracker menggunakan Laravel. Seluruh kode aplikasi berada di
folder [`laravel/`](./laravel/); jalankan perintah Composer, Artisan, dan npm dari
folder tersebut.

Panduan aplikasi dan pengelolaan akun admin tersedia di
[`laravel/README.md`](./laravel/README.md).

Struktur utama aplikasi:

- `laravel/app/` — controller, model, dan provider.
- `laravel/resources/` — stylesheet, JavaScript, dan tampilan Blade.
- `laravel/public/` — entry point serta aset statis yang disajikan web.
- `laravel/routes/` — definisi route.
- `laravel/database/migrations/` — perubahan skema database.
- `laravel/tests/` — pengujian aplikasi.
